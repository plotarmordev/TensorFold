# Drama 3 guidance on CUDA

- Drama 3 on CUDA takes the semantic classifier-free guidance flags Metal has (`--cfg-gamma`, `--cfg-allow-request-gamma`, `--cfg-force-guided`, `--cfg-batched`): each lane's unconditional backbone state is its own, over the conditional engine's weights; only the semantic and end-of-speech logits are mixed, and gamma 1 leaves them bit for bit. A request's guide prefills its every row before its first frame, however few rounds its conditional prompt takes, and a lane's drain waits the guide's stream too, so its failure fails the request and closes the engine with its storage kept. Cancelling or changing the reference clears the guidance state, and opening refuses lanes whose guidance states would not fit the CUDA memory cap. `zig build test-drama-cfg-mix-host` checks the mix kernel's element body against float64 without a GPU, and the CUDA contract runner has `d3_cfg_mix`. This path has not run on a GPU yet: `tools/zig/drama_guidance_check.py` runs the remaining checks on a GB10 with a catalog voice whose reference has over 64 rows, at one prompt row a chunk and at 64 (paired and separate guides give the same PCM on fixed cases, gamma 1 equals the server without CFG, gamma 1.5 and 3 differ from it, every reply has PCM, and each guided server resumed a cached reference), and writes `results.json` as its receipt.
