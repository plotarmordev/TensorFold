# MiniMax-H3-Image on the Spark: an opt-in half-canvas draft start

- `tf-h3-image-cuda` grew `--draft-steps N` (and `--renoise-sigma X`), mmh3's `--draft-steps` ported: the first N steps run on the half-size canvas, and `cascade.zig` does the rest — `cascade.pool` draws the draft's noise from the seed's full draw, `cascade.lift` predicts the clean latent `x + σ·v` from the last draft step's video and velocity, upsamples it bilinearly and renoises it to the next sigma with the seed's detail. Off-grid steps blend the distilled output heads their sigma span covers (`picture.headSpan`, mmh3's `step_heads`) through chained `h3_rows_out` launches with an accumulate-and-scale argument; an on-grid step writes its head bare in one launch (the null-accumulator branch, no memset). The `--serve` path keeps its AdaLN tables on the persistent allocator again — the render/streamSteps split had moved them to the request arena and a second picture walked freed memory.
- Chosen over the PDMD 2-NFE LoRA after studying both (see `docs/recipes/minimax-h3-cuda.md`): the LoRA's weights are published (`yniw/MiniMax-H3-mmh3`, minimax-h3-community-license-agreement — a community agreement, not standard OSS) but unreachable without network staging plus a new adapter through the int8 quantized GEMM stack; drafts need only host resize and reuse every existing kernel. mmh3 reports the LoRA only at 4096² (three-step ~40 s, two-step 29 s vs 62 s in six; 24 s with three drafts and the upscaler on top) and publishes no 2048² LoRA number; drafts alone give it 2048² 18 s → 16 s.
- Measured warm on TOP's GB10 (job `top-0aa72d9f154f`, `bench-drafts.sh` + `H3_DRAFT_STEPS=3`, `--tc` decoder, prompt.txt seed 42, 2048²): **10.7 s** warm mean (transformer 8.3 s) against the six-step `--tc` baseline's 15.3 s; mmh3's own `draft-steps 3` server answers the same request in 6.0 s warm against its 9.3 s six-step. The draft draws a *different* but clean picture — the first build's rainbow moiré was a sign bug (`Rows.clean` did `x − σ·v`; this engine's `v = x₀ − ε` so the clean is `x + σ·v`), fixed by reusing `cascade.lift`, which also removed the copy-paste enlarge/clean/pool re-implementation. Latent cosine vs the episode-1 Mac latent is 0.706 (six-step 0.995); the side-by-side is in the recipe. `--draft-steps` stays opt-in — it is a different picture, so the lead calls whether it becomes more than a flag.
