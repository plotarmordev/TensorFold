# MiniMax-H3-Image on the Spark: an opt-in half-canvas draft start

- `tf-h3-image-cuda` grew `--draft-steps N` (and `--renoise-sigma X`), mmh3's `--draft-steps` ported verbatim: the first N steps run on the half-size canvas, the clean draft is enlarged bilinearly (`picture.enlargeDraft`, mmh3's `resize_video` taps), noised to the next sigma (or the renoise), and the remaining steps finish at full size. Off-grid steps blend the distilled output heads their sigma span covers (`picture.headSpan`, mmh3's `step_heads`) through chained `h3_rows_out` launches with an accumulate-and-scale argument; an on-grid step keeps its own head with weight 1 and bit-identical math. The `--serve` path keeps its AdaLN tables on the persistent allocator again — the render/streamSteps split had moved them to the request arena and a second picture walked freed memory.
- Chosen over the PDMD 2-NFE LoRA after studying both (see `docs/recipes/minimax-h3-cuda.md`): the LoRA path needs weights staged to TOP's pilot folder plus an adapter through the int8 quantized GEMM stack, neither reachable in this card's run; drafts need only host-side resize and reuse every existing kernel.
- Measured warm on TOP's GB10 (job `top-6d575312fd56`, `bench-drafts.sh` + `H3_DRAFT_STEPS=3`, `--tc` decoder, prompt.txt seed 42, 2048²): **10.6 s** warm mean (transformer 8.3 s) against the six-step `--tc` baseline's 15.3 s; mmh3's own `draft-steps 3` server answers the same request in 6.0 s warm against its 9.3 s six-step. **The draft picture is degraded, not merely different** — the output is a rainbow moiré with no recognizable subject (latent cosine −0.11 vs the episode-1 Mac latent; the six-step run is a sharp fox at 0.995), while mmh3's own bilinear `--draft-steps 3` returns a clean fox, so this is a defect in the port's half-grid pass, not the draft idea. The schedule/enlarge/renoise math verifies against mmh3 and passes `picture_test.zig`; the fault is in the half-grid CUDA path and still needs chasing. The default stays six steps and the flag is opt-in and treated as not-yet-shippable until the half-grid output is fixed — see the side-by-side in the recipe.
