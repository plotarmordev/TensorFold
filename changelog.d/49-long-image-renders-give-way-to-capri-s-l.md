# Image renders give way to live speech on the GPU

- The speech server holds a shared lock on `/tmp/tensorfold-speech.lock` while it synthesizes a request (`zig/src/server/gpu_turn.zig`).
- `tf-h3-image` and `tf-h3-dit` yield before forwards, between transformer blocks and after output; profiling also yields between stages. The loader explicitly initializes the coordination state, and each forward resets its wait accumulator.
- Step and profile output separates actual wait seconds from `timing_valid`. A shared generation marker detects requests completed between polls; unknown signals invalidate samples. Benchmarks exclude `timing_valid=false`, even with zero wait. Host regressions cover short and concurrent speech, existing holds, exclusive-lock fallback, and unusable markers.
- Review-fix smoke on Apple M5 Ultra: an isolated branch speech server returned five HTTP 200 audio streams during a 4096-square render, with first audio at 1.600, 1.360, 1.282, 1.346 and 1.107 seconds. Step 1 waited 19.88 seconds and reported `timing_valid=false`; steps 2–6 reported zero wait and valid timings. Final rows matched the earlier render byte-for-byte. The isolated server was stopped; the live release server was unchanged.
- `zig build test test-golden -j1`, the three GPU-turn host regressions and the ReleaseFast developer-tool build passed. Parallel suite runs hit speech-harness header timeouts. Direct benchmark/profile GPU verification remains unmeasured: the available picture case is rejected by the clip benchmark's audio contract.
- Follow-up review brackets the entire wall timer with generation checks, including the final CPU output copies, and corrects the clip recipe to exclude zero-wait invalid samples.
- With the consented Capri reference cache warm, five requests during a 4096 render returned HTTP 200 with first audio at 1.168, 1.174, 1.208, 1.265 and 1.357 seconds. The interrupted step waited 12.68 seconds and was excluded; five subsequent steps were valid. Render rows were byte-identical to the uncoordinated baseline. A cold reference cache still took 14.819 seconds without a render; the sub-three-second result does not cover that startup cost.
