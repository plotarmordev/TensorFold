# MiniMax-H3-Image prompt, AdaLN and decoder on the CUDA blocks

- `tf-h3-image-prompt-cuda` runs Qwen3-VL to layer 50, `condition_proj` and the two-block refiner on CUDA, streaming one layer's BF16 weights at a time. `tf-h3-image-decoder-cuda` decodes the VAE latent in batched tile passes on CUDA with host blending and PNG output. Both expose a synthetic selftest against the float64 host reference, and `run-script.sh` runs all three tools' selftests before rendering either picture size.
- Timestep embeddings and per-block AdaLN projections run on CUDA (`cuda_modulation.zig`) and stay resident across the six denoising steps; only the final norm's table is downloaded, and the host load no longer computes them.
- The prompt runner keeps the canonical cuBLASLt algorithm when it validates at the actual row count and otherwise uses the validated actual-row algorithm with the same FP32 accumulation, output type and required bias epilogue; a host regression covers the real 24-token shape and every rejection mode.
- Decoder norms match Metal's serial warp-partial order with correctly rounded reciprocal square roots and no FMA contraction. Text-encoder products sum K in host-reference order instead of a tiled cuBLASLt reduction. All numerical bounds stay unchanged (block identity 90%), and diagnosis-only capture paths are removed; device clearance needs a new Desk window.
- Prompt and transformer weight transport use two alternating pinned stages, prompt mappings are read ahead, layer buffers are reused, and AdaLN projection weights use pinned staging. The matched table remains the previous ~180 s/~280 s baseline until a post-fix Desk run.
- First GPU checkpoint pictures (`64188519`, TOP's GB10): the CUDA decoder is 56.6/56.2 dB PSNR from Metal's on the same latent, and the CUDA prompt's text rows are cosine 0.99996 from Metal's at identical ids and noise.
- Same window's matched timings: ~180 s wall at 2048² and ~280 s at 4096², against 477 s and 1,128 s when prompt, load and decoder ran on the CPU (the decoder alone 218→7.7 s). mmh3's matched 18.6 s is not beaten.
- The 21 H3 CUDA launches carry nvcc 13.0's measured usage for sm_80/86/89/120/121 and pass the launch-limits gate; the contract's rotary reference rotates from the unrotated vector under the served cos/sin tables, and `h3m_project`'s output is checked as bf16 values in fp32 words.
